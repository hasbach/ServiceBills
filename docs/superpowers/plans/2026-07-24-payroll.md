# Payroll (Employee / SalaryCharge / SalaryPayment) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add per-employee payroll tracking (base salary accrual, bonuses, deductions, payments/advances, running balance) that mirrors the existing Supplier/SupplierPayment ledger pattern, and fold salary cash payments into the existing expense/profit reports exactly the way SupplierPayment already is.

**Architecture:** Three new tenant-scoped SQLAlchemy models — `Employee` (mirrors `Supplier`), `SalaryCharge` (the "what's owed" ledger — salary/bonus/deduction, mirrors the `Expense.is_credit=True` accrual side), `SalaryPayment` (disbursements incl. advances, mirrors `SupplierPayment`). `Employee.balance` is a running ledger: `+= ` for `salary`/`bonus` charges, `-=` for `deduction` charges and for every `SalaryPayment`. Cash-basis accounting: only `SalaryPayment` rows count as an expense, in the same slot as `SupplierPayment`, at all four existing report call sites. A monthly accrual job (APScheduler, mirrors `generate_missing_payments`) posts each active employee's base salary automatically.

**Tech Stack:** Flask + Flask-SQLAlchemy + Flask-Migrate (Alembic, `render_as_batch=True`) + Flask-JWT-Extended, APScheduler `BackgroundScheduler`, pytest (in-memory SQLite via `tests/conftest.py`), React + MUI frontend (`frontend/src`), axios `apiService` in `AppContext.js`.

## Global Constraints

- **Accounting basis: cash.** Only `SalaryPayment.amount` (cash actually paid, including advances) counts as an expense. `SalaryCharge` rows (accrued salary/bonus/deduction) affect `Employee.balance` only, never a report total directly — this is the confirmed design (mirrors `Expense.is_credit=True` vs `is_credit=False` + `SupplierPayment`).
- **Separate `Employee` model**, not a reuse/extension of `User`. `Employee.user_id` is an optional nullable FK to `user.id` for employees who also have a login; most will not.
- **Automatic monthly accrual.** A background job (not a manual "Run payroll" button) posts each active employee's `monthly_salary` as a `SalaryCharge(type='salary')`, mirroring `generate_missing_payments`'s cadence logic (`relativedelta(months=1)` cursor, first charge due one month after `hire_date`).
- **Bonuses/deductions are their own ledger rows** (`SalaryCharge` with `type='bonus'`/`'deduction'`), never inline edits to `Employee.monthly_salary`.
- **A deduction may exceed the current balance and push `Employee.balance` negative.** No floor/clamp, no validation error — this mirrors advances/overpayments already going negative on `Supplier`/`Customer`.
- **Tenant scoping is mandatory and non-negotiable.** Every new table gets `tenant_id = db.Column(db.Integer, db.ForeignKey('tenant.id'), nullable=False, index=True)` verbatim, and every new model class is added to the `TENANT_OWNED_MODELS` tuple (`app.py`) so the `before_flush` listener auto-stamps `tenant_id` on request-scoped creates. Every read/write in a request handler goes through `tenant_query(...)`. The background job takes an explicit `tenant_id` parameter and never calls `tenant_query`, exactly like `generate_missing_payments`.
- **Access control:** Payroll routes use `@admin_required()` (not the plain `@jwt_required()` Supplier uses) — compensation data is more sensitive than supplier data. The frontend nav entry is `allowedRoles: ['admin']` only (mirrors the existing `Expenses`/`Reports` nav items).
- **Ledger rows are append-only.** `SalaryCharge` and `SalaryPayment` have create + list endpoints only — no update/delete — mirroring how `SupplierPayment` and credit-`Expense` rows are never edited from the Supplier UI (the `fix-balance` endpoint is the only correction mechanism, mirrored here too).
- **All file paths absolute** under `C:\Users\InfoCenter\source\repos\delta-net-saas\`.
- **Tests first, in-memory SQLite.** Every task's test goes in `tests/test_iso_payroll.py` (append to the same file across tasks) using the existing `app`/`client` fixtures and `make_tenant` helper from `tests/conftest.py`. Run with `python -m pytest tests/test_iso_payroll.py -v` from the repo root.
- **Frequent commits:** one commit per task.
- **No new abstractions.** Follow the Supplier pattern's inline route-handler style exactly (no service layer, no serializer classes) — that is the codebase's existing convention.

    explicit tenant_id. Mirrors generate_missing_payments's cadence logic."""

                tenant_id=tenant_id, employee_id=employee.id, type='salary'

            last_date = last_charge.date if last_charge else employee.hire_date

                        <Button onClick={() => setEmployeeDialog({ open: false, data: null })}>Cancel</Button>
                        <Button type="submit" variant="contained">Save</Button>
                    </DialogActions>
                </form>
            </Dialog>

            {/* Bonus / Deduction Dialog */}
            <Dialog open={chargeDialog.open} onClose={() => setChargeDialog({ open: false, employeeId: null })} maxWidth="xs" fullWidth>
                <form onSubmit={handleSaveCharge}>
                    <DialogTitle>Add Bonus / Deduction</DialogTitle>
                    <DialogContent dividers>
                        <FormControl fullWidth margin="dense" size="small">
                            <InputLabel>Type</InputLabel>
                            <Select label="Type" value={chargeForm.type}
                                onChange={(ev) => setChargeForm({ ...chargeForm, type: ev.target.value })}>
                                <MenuItem value="bonus">Bonus</MenuItem>
                                <MenuItem value="deduction">Deduction</MenuItem>
                                <MenuItem value="salary">Manual Salary Charge</MenuItem>
                            </Select>
                        </FormControl>
                        <TextField
                            fullWidth autoFocus margin="dense" label="Amount" type="number"
                            value={chargeForm.amount} onChange={(ev) => setChargeForm({ ...chargeForm, amount: ev.target.value })}
                            inputProps={{ step: "0.01", min: "0.01" }} required
                        />
                        <TextField
                            fullWidth margin="dense" label="Reason" value={chargeForm.reason}
                            onChange={(ev) => setChargeForm({ ...chargeForm, reason: ev.target.value })}
                        />
                    </DialogContent>
                    <DialogActions>
                        <Button onClick={() => setChargeDialog({ open: false, employeeId: null })}>Cancel</Button>
                        <Button type="submit" variant="contained" color="warning">Save</Button>
                    </DialogActions>
                </form>
            </Dialog>

            {/* Pay Salary / Advance Dialog */}
            <Dialog open={paymentDialog.open} onClose={() => setPaymentDialog({ open: false, employeeId: null })} maxWidth="xs" fullWidth>
                <form onSubmit={handleRecordPayment}>
                    <DialogTitle>Pay Salary / Advance</DialogTitle>
                    <DialogContent dividers>
                        <Typography variant="body2" sx={{ mb: 2 }}>
                            Enter the amount you paid this employee. This reduces the balance owed (an advance can push it negative).
                        </Typography>
                        <TextField
                            fullWidth autoFocus margin="dense" label="Amount Paid" type="number"
                            value={paymentForm.amount} onChange={(ev) => setPaymentForm({ ...paymentForm, amount: ev.target.value })}
                            inputProps={{ step: "0.01", min: "0.01" }} required
                        />
                        <TextField
                            fullWidth margin="dense" label="Method" value={paymentForm.method}
                            onChange={(ev) => setPaymentForm({ ...paymentForm, method: ev.target.value })}
                        />
                        <TextField
                            fullWidth margin="dense" label="Note" value={paymentForm.note}
                            onChange={(ev) => setPaymentForm({ ...paymentForm, note: ev.target.value })}
                        />
                        <FormControlLabel
                            control={<Switch checked={paymentForm.is_advance}
                                onChange={(ev) => setPaymentForm({ ...paymentForm, is_advance: ev.target.checked })} />}
                            label="This is an advance"
                            sx={{ mt: 1 }}
                        />
                    </DialogContent>
                    <DialogActions>
                        <Button onClick={() => setPaymentDialog({ open: false, employeeId: null })}>Cancel</Button>
                        <Button type="submit" variant="contained" color="success">Record Payment</Button>
                    </DialogActions>
                </form>
            </Dialog>

            {/* Action History & Fixed Balance Dialog */}
            <Dialog open={historyDialog.open} onClose={() => setHistoryDialog({ open: false, employee: null, history: [] })} maxWidth="md" fullWidth>
                <DialogTitle>Employee Action History & Balance Management</DialogTitle>
                <DialogContent dividers>
                    {historyDialog.employee && (
                        <Box sx={{ mb: 3, p: 2, bgcolor: alpha(theme.palette.primary.main, 0.05), borderRadius: 2 }}>
                            <Typography variant="subtitle1" fontWeight={600}>{historyDialog.employee.name}</Typography>
                            <Box sx={{ display: 'flex', alignItems: 'center', gap: 2, mt: 1, flexWrap: 'wrap' }}>
                                <Typography variant="body2">Fixed Balance:</Typography>
                                <TextField
                                    size="small"
                                    label="Amount ($)"
                                    type="number"
                                    inputProps={{ step: "0.01" }}
                                    value={fixBalanceInput}
                                    onChange={(e) => setFixBalanceInput(e.target.value)}
                                    sx={{ width: 180 }}
                                />
                                <Button variant="contained" size="small" onClick={handleFixBalance}>
                                    Set Balance
                                </Button>
                            </Box>
                        </Box>
                    )}

                    {historyLoading ? (
                        <Box sx={{ display: 'flex', justifyContent: 'center', p: 4 }}><CircularProgress /></Box>
                    ) : (
                        <TableContainer>
                            <Table size="small">
                                <TableHead>
                                    <TableRow>
                                        <TableCell><b>Date</b></TableCell>
                                        <TableCell><b>Type</b></TableCell>
                                        <TableCell><b>Description</b></TableCell>
                                        <TableCell align="right"><b>Amount</b></TableCell>
                                    </TableRow>
                                </TableHead>
                                <TableBody>
                                    {historyDialog.history.map((h) => (
                                        <TableRow key={h.id}>
                                            <TableCell>{h.date}</TableCell>
                                            <TableCell>
                                                <Chip size="small" label={h.title} />
                                            </TableCell>
                                            <TableCell>{h.description}</TableCell>
                                            <TableCell align="right" sx={{ fontWeight: 600, color: h.amount > 0 ? 'error.main' : 'success.main' }}>
                                                {h.amount > 0 ? `+$${h.amount.toFixed(2)}` : `-$${Math.abs(h.amount).toFixed(2)}`}
                                            </TableCell>
                                        </TableRow>
                                    ))}
                                    {historyDialog.history.length === 0 && (
                                        <TableRow>
                                            <TableCell colSpan={4} align="center" sx={{ py: 3, color: 'text.secondary' }}>No action history found.</TableCell>
                                        </TableRow>
                                    )}
                                </TableBody>
                            </Table>
                        </TableContainer>
                    )}
                </DialogContent>
                <DialogActions>
                    <Button onClick={() => setHistoryDialog({ open: false, employee: null, history: [] })}>Close</Button>
                </DialogActions>
            </Dialog>
        </Box>
    );
}

export default EmployeesView;
